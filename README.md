# 🤖 Desafio 10: Site da História do Android

Este é um projeto desenvolvido como conclusão do **Desafio 10** do curso de **HTML5 e CSS3**, realizado através da plataforma **Estudonauta**, sob a orientação do professor **Gustavo Guanabara**.

O grande objetivo deste desafio foi criar uma página web fluida e adaptável para telas menores **sem o uso de Media Queries**, aplicando conceitos inteligentes de dimensionamento, limites de largura e design responsivo nativo.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando:
* **HTML5:** Estruturação semântica completa da página (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`).
* **CSS3:** Estilização avançada, uso de variáveis (`:root`), fontes personalizadas do Google Fonts e efeitos de sombra.

---

## 💡 Aprendizados e Conceitos Praticados

Durante o desenvolvimento deste desafio no Estudonauta, pude consolidar conhecimentos em:
- **Responsividade Fluida:** Uso estratégico de `max-width`, `min-width` e margens automáticas (`margin: auto`) para que o layout se adapte perfeitamente a celulares e desktops de forma natural.
- **Variáveis CSS:** Centralização da paleta de cores (tons de verde do Android) para manter o código limpo e de fácil manutenção.
- **Tags Semânticas:** Organização estrutural impecável para melhorar a acessibilidade e o SEO da página.
- **Estilização de Elementos Especiais:** Customização de listas personalizadas e inserção de vídeos responsivos.

## 🛠️ Como Executar o Projeto

Se quiser rodar o projeto localmente na sua máquina:

1. Clone este repositório:
   ```bash
   git clone git@github.com:paulowenderson/.desafio-dez-android.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd .desafio-dez-android
   ```
3. Abra o arquivo `index.html` em qualquer navegador web.
